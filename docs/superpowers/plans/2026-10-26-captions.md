# Captions by Claude + Temporary English Captions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Non-English/non-Filipino jobs get a temporary English caption track from the first build, and step 10 lets the editor choose CapCut auto-caption, Claude's CapCut text captions, or Claude's animated captions, all made by tools from the script and VO word timings.

**Architecture:** A new `captions.py` turns script lines + VO word timings (mapped through the timeline's real VO segments) into caption chunks and temporary-English rows. `media_timing` learns other languages. `build_project` adds the TEMP_EN track at build and makes caption drafts at step 10; `capcut_project` merges text tracks and fixes their layer; `qa_check` gains a `captions` subcommand and exempts TEMP_EN; `edit_diff` never learns the TEMP_EN deletion. Docs change the "never add captions" rule.

**Tech Stack:** Python 3.12 (venv `.claude/edit-mo-to/tools/.venv`), pytest, faster-whisper, VectCutAPI on :9001, HyperFrames (`ugc-captions` template).

**Spec:** `docs/superpowers/specs/2026-10-26-captions-design.md`

## Global Constraints

- English jobs: `media_timing` output, model (`small.en`) and transcript cache keys are byte-for-byte unchanged.
- No new ⛔ gate: SKILL.md stays at 26 ⛔ symbols, steps.md at 2; only step 10's question wording changes.
- Every write to a CapCut project goes through `capcut_project.py` (busy check, backup, last snapshot).
- Motion templates are not edited.
- Temporary track name is exactly `TEMP_EN_delete_me`; it is the top text layer; Claude's real caption track is named `captions`.
- Caption words are the script's words; times in whole frames at 30 fps.
- Tests in `tools/tests/`, run with `"{python}" -m pytest tests -q -m "not slow" -p no:cacheprovider`; real-API tests skip when :9001 is down; real renders are `slow`.

## Review Focus

- A script line with accented words (Spanish "¿Sabías que…?", German "Größe") gets timings and matches (`matched: 1`).
- The editor trimmed the VO in CapCut (one VO segment split in two with a 2 s cut): captions skip the cut words and shift the rest.
- A plain English job: no TEMP_EN track, no extra rows, identical vo JSON.
- Adding captions twice to the same timeline is refused, not duplicated.
- The editor deleted TEMP_EN: no `text:removed` pattern is logged.

### Task 2: `captions.py` (chunks, timeline mapping, temporary English rows)

**Files:**
- Create: `.claude/edit-mo-to/tools/captions.py`
- Test: `.claude/edit-mo-to/tools/tests/test_captions.py`

**Interfaces:**
- Consumes: `media_timing` vo JSON (`words[]` `{word,start,end}`, `lines[]` `{line,start,end,matched}`); `capcut_project.segments()` dump (VO = `track_type=="audio"` and `track` starts with `"vo"`; `at`, `duration`, `src_in`, `speed` in seconds).
- Produces:
  - `script_words(words: list[dict], script_lines: list[str]) -> list[dict]` — the script's words with ASR times by character alignment (same idea as `ugc-captions`): `{word, start, end, line}`.
  - `chunk(words: list[dict], max_words=4, max_chars=22, pause=0.25) -> list[dict]` — `{text, start, end, words}`; rules: cut first at hard stops (`.!?:…`, end of script line), soft stops (`,;—–`) and gaps > `pause`; numbers stay with the next word, `%` with the number; no one-word chunk unless the phrase is one word; chunks ≤ `2*max_chars` chars; a chunk shown < 0.5 s merges with a neighbour in the same sentence; each chunk ends at the next chunk's start or its last word + 0.3 s.
  - `to_timeline(words: list[dict], dump: dict, vo_in: float = 0.0) -> tuple[list[dict], list[dict]]` — maps file-time words onto timeline time through the dump's VO segments (`t_tl = seg.at + (t_file - seg.src_in) / seg.speed`), returns `(kept, dropped)`; a word is kept only if its whole span lies inside one VO segment.
  - `temp_en_rows(lines: list[dict], english: list[str]) -> list[dict]` — one `{text, at, duration, style: "temp_en"}` per script line with its English line (lines and English must have equal counts, else `ValueError`).
  - CLI: `captions.py chunks <vo.json> <script.txt> <project> "<timeline>" [--max-words 4] --out chunks.json` (prints `{chunks, dropped_words, out}`); `captions.py temp-en <vo.json> <script_en.txt> --out rows.json`.

- [ ] **Step 1: Failing tests**
  - `test_chunks_cut_at_punctuation_and_pause`: "Hi there, friend. How are you" (gap 0.4 s after "friend.") → `["Hi there, friend.", "How are you"]`.
  - `test_no_one_word_orphan_and_number_glue`: "Save 50 % today now" → no chunk is a single word; "50 %" stays in one chunk.
  - `test_short_chunk_merges`: a 2-word chunk shown 0.3 s merges into its neighbour in the same sentence.
  - `test_to_timeline_follows_a_trim`: VO segments `[{at:0,dur:2,src_in:0},{at:2,dur:3,src_in:4}]`; a word at file 3.0–3.4 is dropped, a word at file 4.5–4.9 lands at timeline 2.5–2.9.
  - `test_script_words_replace_asr_spelling`: ASR `"seventy","percent"` against script "70 %" → words `["70", "%"]` with the ASR times.
  - `test_temp_en_rows_one_per_line` and `test_temp_en_count_mismatch_raises`.
