# edit-mo-to Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `/edit-mo-to` workflow: an orchestrator skill, 5 style agents, an editor agent, a QA agent, a learned-preferences store, and two Python tools (CapCut multi-timeline project tool, VO timing/beat tool).

**Architecture:** The skill runs the user's 12 gated steps in the main conversation and hands self-contained work to subagents. Style agents write prompts and edit plans. The editor turns an edit plan into CapCut drafts through the `capcut` MCP server, then uses `capcut_project.py` to compose or extend multi-timeline projects. QA checks the brief, script, prompts and build. Timing comes from `media_timing.py` (faster-whisper word timestamps, librosa beats).

**Tech Stack:** Claude Code skills and subagents (Markdown + YAML frontmatter), Python 3.12 venv (faster-whisper 1.2.1, librosa, pytest), ffmpeg/ffprobe, CapCut MCP + VectCutAPI (`capcut_legacy` drafts), CapCut 9.6.

**Spec:** `D:\Video Editing\docs\edit-mo-to-design.md`

## Global Constraints

### Task 2: Media timing tool

**Files:**
- Create: `D:\Video Editing\.claude\edit-mo-to\tools\media_timing.py`
- Create: `D:\Video Editing\.claude\edit-mo-to\tools\tests\test_media_timing.py`

**Interfaces:**
- `to_sf(seconds: float, fps: int = 30) -> str`: `to_sf(7.4) == "7:12"`, `to_sf(0) == "0:00"`, `to_sf(59.999) == "60:00"` (rounds to the nearest frame, and frames always have 2 digits).
- `transcribe(audio: Path) -> list[dict]`: words as `{"word", "start", "end"}`, using faster-whisper `small.en`, `word_timestamps=True`.
- `align_lines(words: list[dict], lines: list[str]) -> list[dict]`: each line becomes `{"line", "start", "end", "start_sf", "end_sf", "duration", "matched"}`. Matching is fuzzy and in order (normalised tokens, difflib).
- `beats(audio: Path) -> dict`: `{"tempo", "beats": [sec...], "beats_sf": [...]}` via librosa.
- CLI: `python media_timing.py vo <audio> <script.txt>` (one line per script line) | `beats <audio>`. Prints a JSON table.

  - `test_beats_on_click_track`: generate a 120 BPM click wav with numpy, and expect tempo within ±2.
